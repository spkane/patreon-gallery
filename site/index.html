01 / Set up your scout

A local install.
No password handoff.

  1. Get the files

    Clone or download the source repository and keep its extension folder. If a packaged beta is available, use GitHub Releases and extract it.

  2. Load in Chrome

    Visit chrome://extensions, turn on Developer mode, choose Load unpacked, and select the folder containing manifest.json. Review the permissions.

  3. Open your membership

    Sign into Patreon normally, open a creator's Posts page, then click Gallery Scout. Choose a detected feed and load its posts.

02 / Find your starting point

From the beginning.
Or where you left off.

Load oldest post and Load oldest unread post scan the archive, clear filters and sort cards oldest-first. Opened markers stay in this browser profile—not Patreon's read state.

The media viewer browses images, videos and files. Text cards open the original post. Scans are cancellable and capped at 100 pages, so very large archives may be incomplete.

Download saves; Open views. Native formats may need a download followed by a second click. Check Chrome Downloads for completion. YouTube actions export URL lists for a separately installed tool; they do not download video files.

03 / Know the boundaries

Small footprint.
Clear permissions.

The extension requests access to www.patreon.com, bundled script injection, downloads and user-initiated file opening. It does not ask for cookie-reading or all-website permissions.

No extension analytics or maintainer backend. Patreon and media providers receive normal browser requests; Chrome may keep source URLs in download history.
