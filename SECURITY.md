# Security policy

Gallery Scout is experimental. Security fixes target the current source version; older ZIPs should be replaced. This policy does not promise a response SLA or certify the software.

## Reporting

Do not post vulnerabilities, signed URLs, cookies, tokens or private creator data in public issues. Use GitHub's **Report a vulnerability** option on this repository if private reporting is enabled. If it is unavailable, contact the maintainer through their GitHub profile to arrange a private channel; do not send sensitive details until that channel is agreed.

Include the extension version, Chrome version, reproduction using synthetic/public data, impact, and a proposed fix if available. Never provide passwords or session exports.

Maintainers should enable private vulnerability reporting before public release. The localhost OAuth demo is a development experiment, not a hardened public service.

See the permissions/security audit and access-risk review linked from the README.
