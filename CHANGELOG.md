# Changelog

## 0.3.4 — release preparation

- Harden extension runtime sender validation and sanitize unexpected background errors.
- Document permissions, privacy, access/distribution risks and manual release gates.
- Make the README extension-first; retain historical OAuth notes separately.
- Add allowlisted, reproducible ZIP packaging and automated release checks.
- Add a static GitHub Pages project site and deployment workflow (not yet published).
- Adopt Apache-2.0 for project code; creator media remains outside the license.

- Include text posts in chronological start selection.

## 0.3.2

- Recognize multiple YouTube links in viewable post bodies and export canonical URL lists.
- Make plain post covers clickable.

## 0.3.1

- Remove duplicate fullscreen iframe attributes.

## 0.3.0

- Separate Open/Download actions and improve file display.
